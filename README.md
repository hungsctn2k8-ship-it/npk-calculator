# NPK Calculator

Chương trình Python đơn giản giúp tính toán tỉ lệ phần trăm các thành phần dinh dưỡng Nitơ (N), Phốt pho (P₂O₅), và Kali (K₂O) có trong một khối lượng hỗn hợp phân bón xác định.

## Tính năng
- Tính chính xác tỷ lệ phần trăm theo khối lượng đầu vào.
- Làm tròn kết quả trực quan theo tiêu chuẩn công thức phân bón thương mại (Ví dụ: 16-16-8, 20-20-15).
- Kiểm tra tính hợp lệ của dữ liệu đầu vào.

## Cách chạy chương trình
1. Máy tính của bạn cần cài đặt sẵn Python 3.
2. Tải file `main.py` về máy.
3. Mở terminal/cmd tại thư mục chứa file và chạy lệnh:
   ```bash
   python main.py
   ```
4. Nhập các thông số khối lượng theo yêu cầu hiển thị trên màn hình để nhận kết quả.
